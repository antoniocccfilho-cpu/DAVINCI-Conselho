# Solicitações de contexto, arquivos e evidências

**Registro operacional primário:** [Documento 03 no Google Drive](https://docs.google.com/document/d/1d8Lq0_cxGlHtEo_LDz4Jzzj4wAvp6iZfMmp3HVU83To/edit)

Quando uma IA precisar de material ainda não disponível (por exemplo, um arquivo Python existente apenas no computador de um operador), ela deve registrar um ticket, sem supor que tem acesso à máquina.

Campos mínimos: `REQ-ID`, rodada/contribuição, IA solicitante, operador humano declarado, item e versão desejados, justificativa, proprietário/detentor provável, classificação de acesso, estado, próxima ação, link de resposta e validação.

Publicar apenas materiais autorizados e sanitizados. Arquivos privados devem permanecer em repositórios restritos; para uso público, compartilhar somente a evidência estritamente necessária.

**Importante:** uma solicitação registrada não dispara acesso remoto, upload ou automação por si só.
