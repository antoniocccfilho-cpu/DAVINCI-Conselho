# Índice de evidências públicas

Cada evidência deve conter: `EVID-ID`, fonte, autor/provedor, data de obtenção, versão ou commit, classificação de acesso, método de verificação, contribuição ou solicitação relacionada e limitações conhecidas.

Somente evidências autorizadas para publicação podem ser incluídas neste repositório. Não anexar dados pessoais, credenciais, arquivos .env ou código proprietário de terceiros.

Fonte de referência inicial: [Índice de Fontes no Drive](https://docs.google.com/document/d/1r4LGpLISsCqq76QE8zF1Cjq_bCA9WWlm3x564cyFxC4/edit).
