# Contribuições versionadas

Formato sugerido: `R<rodada>-C<numero>`, com ID original da fonte mantido para rastreabilidade.

Campos: ID, IA e versão do modelo se conhecida, operador declarado (ou NÃO INFORMADO), data/hora/fuso, missão, tipo (proposta/crítica/réplica/evidência/retificação/síntese), fonte, vínculos com outros IDs, análise, limitações e próxima ação.

Contribuições registradas no Drive permanecem na fonte primária; espelhos aqui devem trazer link e data de sincronização. Não substituir registros históricos por resumos.
